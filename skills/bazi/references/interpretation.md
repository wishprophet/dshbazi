# 生活化批语与年度解释

## 十二维度

对外写“这个方面整体怎样，以及生活中主要怎样表现”。证据在内部核对，不把规则编号、局限与条件列表排进正文。标题优先使用数据里的 `publicTitle`；下表用于没有该字段时的对应，不改内部维度 ID。

| 内部维度 | 公开标题 | 写成生活中的情况 |
|---|---|---|
| 格局层次 | 整体发展 | 格局与组合的长处、受制处，发展靠什么，起伏主要在哪里 |
| 官禄功名 | 事业工作 | 职业发展偏稳还是多变，岗位、责任、成绩与上级关系怎样衔接 |
| 财禄丰啬 | 收入积累 | 收入来源、回款、支出节奏、积累与财务安排 |
| 六亲伦常 | 家庭亲情 | 家庭支持、长辈沟通、照料责任、家人分工 |
| 婚姻妻室 | 感情婚姻 | 婚缘顺逆、稳定成家早晚，有运年支持的年龄窗口及婚后相处 |
| 学业文名 | 学习成长 | 课程、考试、资格申请、表达与成果展示 |
| 疾厄寿元 | 身心状态 | 忙碌与休息、压力来源、作息和精力安排 |

| 官非灾讼 | 纠纷与麻烦 | 合同、手续、合作边界、沟通争议 |
| 心性品行 | 性格处事 | 决策习惯、表达方式、遇到压力时的反应 |
| 人际交友 | 朋友合作 | 同伴支持、团队合作、竞争和利益分配 |

## 从信号到具象情景

先在内部辨认“责任增加”“流动”“竞争”“关系协商”等主题，再挑出最贴合该年资料的一两种表现。只有 `contextYear` 当年的职业、婚恋和计划可以直接用于该年批语；相邻年份也不能默认沿用。

每年检查全部十二领域，再选有具体异动的领域；不能固定只选事业、学习、外出。家庭照料、朋友合作、收支、感情、住房、纠纷和做事习惯等出现突出信号时，应直接写对应事情。没有显著变化可以少写或不列事件。月份只取 `focusMonths` 的突出窗口，避免每年固定两个月、每月固定一件事，不给读者展示月度分数。

以下仅演示写法。假设当年的工具证据确实支持工作责任增加，而且用户说明那一年在准备内部竞聘：

> 这一年工作上的存在感会增强，更容易被交付一项需要独立负责的任务。竞聘过程中，实际项目成绩比口头表达更能帮上忙；忙碌主要集中在交接、协调和考核。

若当年是学生，对应课程项目、考试或实习责任；当年在创业，则考虑客户验收、业务承诺和团队协调。只写与该年已知情况相符的分支，不把所有人群的情景逐项罗列。没有职业背景时可以写任务、安排与合作等具体事项，不虚构单位、职级或老板。

弱的写法：“事业财运有好有坏，婚恋可能变化，要注意小人。”

改进方式：说清这一年最突出的事情及其生活表现。事件有 `reading` 时以它为起点，用 `publicTitle` 作短标题；核对 `evidence`、`condition`、`counterEvidence` 后再取舍，不把这些字段原样朗读。缺乏依据时少下判断，不用新增神煞、断语或分数填补。

## 总评与语言

总评以 `analysis.overview` 为起点，先读取 `summary`，再核对 `pattern`、`career`、`marriage`、`wealth` 的结论及依据。正文回答“发展靠什么、事业稳不稳、财能否留住、婚缘顺不顺和早晚”，不要只写“有主见、肯努力、注意沟通”。同一个命盘的总评与十二方面不能互相打架；若某方面只支持局部判断，就收窄这一句，不用泛泛建议填满。

句子先给判断，再用最关键的组合说明具体表现。例如工具同时支持职业变动和专业积累时，可以写“事业变动较多，岗位或发展方向容易几经调整；专业积累能接续下来，换环境后仍有重新站稳的本钱。”有真实婚期窗口时可写“稳定成家偏晚，较集中的成家窗口在约 X—Y 岁（A—B 年）。”年龄与年份必须替换为工具实际给出的值，不把示例变成每个人的结论。

少量命理名称可以保留，但要与生活判断连起来。格局名称说明结构，成败、制化与行运说明这条路是否顺手；不能看到正官就写“事业平稳”，见到财星就写“有钱”，看到日支冲就写“30岁才结婚”。程序只给组合倾向时，直接说对应表现，不自行补一个已成的格局，也不向读者朗读“尚未审定”等内部状态。

同年工作压力上升与支持增加可以同时存在，可写“事情比往年多，但能得到更多配合”。不要为求直截了当，把不同领域强行合成绝对好坏。把把握程度放在措辞中，不另外附上限制、免责声明或需保留条件。

婚缘时间先区别“认识与交往”“定亲成家”“婚后关系调整”。原局关系特点、配偶星与夫妻宫、大运及流年要共同核对；一个刑冲不能同时包办不顺、晚婚和离婚三个结论。只能采用成年运年中有多重支持的少量窗口，不按最高分强行挑一年。缺出生年或起运资料时不报成家年龄；明确已婚的对应年份，不再预测首次成婚。用户提供的已知经历用于选对解释场景，不能被说成预先断中的事实。

## 内部检查，不公开朗读

- 四柱和日期计算、趋势数值、规则证据完整保存在 JSON；公开文字不展示算法来源、规则版本、编号或技术口径。
- 核对月令、透干、根气、格局受制与救应，再判断事业的稳定性和主要阻力。格局名称、格局是否成立、行运是否支持分别处理，不把缺少成败判断的标签升级为确定的人生结论。
- 已知经历用于理解该年，不能冒充事先算中的事实。未来不编造明确人物、金额或精确事件日期；工具给出的年份、年龄窗口可以直接表达，但不改写成必然发生的日期。
- 只输入四柱且缺起运时，先完成本命部分；影响人生走势的缺项只用一句话说明需要补什么。
- 不把传统标签直接推出官阶、资产额、疾病诊断、寿命、死亡、犯罪、牢狱、必然离婚或亲属生死；不在报告末尾再重复这些边界。
- 人生主图逐年连接实际 `score`，保留内部 OHLC 与流月数据；不人为改线、补点或平滑。
