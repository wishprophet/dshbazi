# 十二维度与年度解释

## 十二维度

各段可采用“概评—依据—现实表现—条件”四句结构。证据来自工具中的盘面、关系与规则结果；不可从维度名称反推缺失证据。

| 维度 | 适合落到的现实问题 | 不应直接推出 |
|---|---|---|
| 格局层次 | 日主与月令、规则中的成格条件、制化关系、优势与制约 | 具体社会阶层、官阶、终身成败 |
| 官禄功名 | 岗位责任、考核、组织协作、管理压力、职业转换 | 必升官、必失业 |
| 财禄丰啬 | 劳动收入结构、业务回款、消费与现金流安排 | 精确收入、资产额、投资回报 |
| 六亲伦常 | 家庭责任、沟通方式、长辈支持、照料安排 | 亲属疾病、死亡、品德 |
| 婚姻妻室 | 亲密关系节奏、沟通、共同计划、家庭分工 | 配偶身份、出轨事实、必然离婚 |
| 学业文名 | 学习投入、资格考试、写作表达、成果展示 | 确定录取、精确分数、最高学历 |
| 疾厄寿元 | 作息稳定度、压力主题、生活与休息安排 | 医学诊断、患病概率、寿命 |
| 迁徙驿马 | 差旅、搬迁、跨部门跨城市流动、远程合作 | 必出国、精确搬家日期 |
| 家宅田宅 | 居住安排、装修沟通、家庭预算与产权资料整理 | 具体房产数量、交易价格 |
| 官非灾讼 | 合同细节、流程合规、合作边界、争议协调 | 犯罪认定、牢狱、判决结果 |
| 心性品行 | 决策习惯、表达方式、压力下的反应 | 人格诊断、道德评价 |
| 人际交友 | 同事合作、资源互助、关系边界、意见分歧 | 特定人物动机或背叛事实 |

## 从信号到具象情景

先识别证据支持的是“责任增加”“流动”“竞争”“关系协商”等主题，再依据现实背景选少量解释。一个主题可映射多种事件，但不能把这些互斥事件全部写成预测。

示例仅演示格式，不是任何命盘的结论：

> 年度主题：职责与考核压力更突出。若你仍在现单位、正在准备竞聘，今年值得关注的具体情景是承担临时负责人工作、跨部门项目或参加内部选拔。依据是工具返回的本年职业维度变化及相应规则；仍需核实单位是否确有岗位空缺。可观察信号是书面任命、考核指标调整或新增项目职责，不能据此保证晋升。

若用户是学生，应把相关主题解释为课程项目、考试、社团或实习责任；若正在创业，则考虑客户验收、业务承诺、组织协调。用户背景没有提及的分支不用逐一展开。

弱的写法：“事业财运有好有坏，婚恋可能变化，要注意小人。”

改进方式：写清哪个维度、哪条证据、什么条件下的哪种事件、怎样观察。没有这些依据就降低强度或略去该主题，不用新增神煞或任意分数填补。

## 保留验证边界

- 过去经历可以用于理解用户处境，但不能证明规则有预测效力。
- 对已知年份复盘时标明“事后解释”；未知未来写“条件性情景”。
- 同年工作压力上升与资源支持增强可以同时存在，解释其作用对象，不硬合成一个绝对吉凶标签。
- 只输入四柱且缺起运时，可以解释本命与公历流年干支关系；凡涉及某岁交运、某步大运或月度精确转折，必须依赖工具明确提供的数据。
