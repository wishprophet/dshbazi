## 当前边界

用户提供的线上实例首页重定向至登录页，当前没有已认证会话，未向该实例写入或更新插件。目标 SDK 已在上述官方 rc.1 组件环境中验证；实际 profile 更新后仍需确认工具和 skill 出现。

网站表单已核查的公历范围为1902—2038；本地入口接受1901—2100出生日期。网站不接收秒数，非零秒在auto模式降级本地并说明。农历先转公历提交，保留分钟。

统一使用北京时间钟表时间、23点换日；出生地点记档，不自动处理真太阳时或境外历史时区。农历闰月显式标识。

首版分析规则为可追溯的简化传统框架，未覆盖所有特殊格局和调候条件。通过排盘和软件测试不能证明命理事件预测有效。完整成文细批由DSH模型结合skill和用户现实背景完成；HTML包含程序生成的生活化批语与图表，不额外调用外部大模型。
