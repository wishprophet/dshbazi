# 称骨资料与版本

本页供开发和复核使用，不整段进入用户报告。

## 本版选用

- 标题使用用户确认的“袁天罡称骨”。这是流传名称，不宣称已经证明歌诀由袁天罡本人撰写，也不署名诸葛亮。
- 使用常见的农历年月日时四表，整数单位为钱，十钱为一两。年表按六十甲子从甲子起排列；月表12项、日表30项、时表12项。可计算总重21至71钱，不制造72钱结果。
- 歌诀采用传统通行四句本，男女共用；不混入来历不清的网络女命散文、定寿长篇或作者自创断句。简繁字与标点规范化；异文取舍固定在 `src/data/chenggu.js`，不宣称存在唯一权威原本。
- 白话全部由本项目重新撰写，是对对应诗句的释义。既不把低骨重改写为相反的吉语，也不把原诗的古代官职、贫富及寿命修辞落实成当事人的事实。
- 年以农历正月初一换年；月份按农历，闰月整月使用同名月份；日期使用民用农历日期，23点按子时取时重但日期不进位。称骨和子平的历法用途不同，不直接拿立春年柱代替农历年。
- 结果是独立的诗文查表，不加进子平格局、年度评分，也不控制人生走势图的截止年份。

## 核对资料

1. [《大杂字不求人》台大馆藏扫描本](https://commons.wikimedia.org/wiki/File:NTUL-9900007270_大雜字不求人.pdf)，其中“袁天罡先师神数秤骨分量照年月日時推算”“秤骨歌”收有旧式年、月、日、时表及四句歌。此古本用来确认传统文本与旧式措辞；网站OCR有栏位错配，不能把OCR标题当成可靠的逐项表号。
2. [观易堂称骨四表](https://guanyitang.com/chenggu)：核对60年、12月、30日、12时的整数表值、21至71钱范围；该站的现代评语不采用。
3. [ezfate称骨对照表](https://ezfate.com/zh/bazi-weight/chart)：交叉核对四表，以及简体通行四句诗对应的重量档位。只使用传统表值和古歌，不复制该站白话、概率或现代读法。
4. [《袁天罡称骨算命法》资料PDF](https://d.zixueguoxue.com/2020/04/2020041001123848.pdf)：核对农历1971年正月初一子时的公开算例，17＋6＋5＋16＝44钱。其年份表有明显印误，故不作为唯一表源。
5. [称骨计算示例：闰月按同月](https://astrologybazi.com/chenggu)：核对闰月同月作为实际流传口径之一；不声称所有版本都一致。

## 已知异文和取舍

- 癸亥年在部分网络表写七钱，本版与两份完整四表一致采用六钱；庚辰年采用一两二钱，未采个别PDF的一两。
- 闰月有“全月同月”与“十五前同月、十六后下月”两种；本版固定全月同月，不偷偷调整，也不混用两种结果。
- 晚子时也有日进位版本；本版固定民用农历日，不借用子平23点换日结果。
- 四两四钱采用“万事由天莫苦求，须知福禄胜前途，当年财帛难如意，晚景欣然便不忧”这一流传形式；未采用部分网页改作“须知福禄赖人修”的文字。其余各档也保留固定通行读本，而不以网站最新改文自动替换。
- 原歌二两一钱有“短命非业”等凶断。原文照录供阅读，白话说明诗意，不生成死亡日期、寿命数字或暗示死亡的图表终点。
